# 历史人物匹配 · H5 趣味测试

移动端优先的中文性格测验，风格参考小红书「历史人物匹配」类结果页（紫白软审美、六段结果卡片）。

## 如何打开

### 本机浏览器
直接打开文件：
```
/workspace/historical-figure-quiz/index.html
```
或在项目目录启动静态服务后访问：
```
http://127.0.0.1:8765/
```

### 手机访问（同一局域网）
1. 在电脑上保持 `python3 -m http.server 8765` 运行
2. 查看电脑局域网 IP（如 `192.168.x.x`）
3. 手机浏览器打开：`http://<电脑IP>:8765/`

也可把整个文件夹发到手机，用系统浏览器直接打开 `index.html`（离线可用）。

## 使用说明
1. 首页点击「开始测试」
2. 完成 15 道单选题（可返回上一题）
3. 查看匹配结果；左右滑动浏览 6 段卡片
4. 「再测一次」重新作答；「复制结果文案」便于分享
5. 结果页或首页的「查看上次结果」打开这一台设备上保存的上次结果

## 订单号

首页输入订单号后开始。订单号在页面上做格式检查。格式通过就进入测验，不请求 `*.vercel.app`，也不读写 Mantle 的 `orders/` 或 `hq/`。`paidVerified` 保持为 false。

| 项 | 值 |
|---|---|
| 格式 | 只接受 `P` + 18 位。重复块和逐位 ±1 的序列在页面上拒绝，19 位也不接受，提示「订单号格式不对」 |
| 通过 | 立刻解锁并开始，没有绑定、没有限流、没有服务器次数 |
| 显示 | 第一次开始记 1 次，提示「验证成功，还可以测 2 次」。再测一次再记 1 次 |
| 不记 | 刷新、继续这一次、查看上次结果、刷新结果都不改显示次数 |
| 记满之后 | 仍然可以进入，提示「验证成功」，不拦截 |
| 存放 | 按订单号记在这台浏览器的 `localStorage`，键 `history_quiz_order_uses` |

## 已发出的访问码

已经发出的 `LS` 码仍先 `POST /redeem`（quiz 键 `history`）。vault 明确用尽则不再落到 Mantle；vault 没有这枚码时才回退 Mantle `hq/`，剩余次数仍是跨设备的真实计数。同一标签页里已经解锁之后，「再测一次」不重复扣次。卖家说明见 [CODES.md](CODES.md)。
