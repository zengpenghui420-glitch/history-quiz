# 历史人物匹配 · H5 趣味测试

移动端优先的中文性格测验，风格参考小红书「历史人物匹配」类结果页（紫白软审美、六段结果卡片）。

## 如何打开

### 本机浏览器
直接打开文件：
```
/workspace/historical-figure-quiz/index.html
```
或在项目目录启动静态服务后访问：
```
http://127.0.0.1:8765/
```

### 手机访问（同一局域网）
1. 在电脑上保持 `python3 -m http.server 8765` 运行
2. 查看电脑局域网 IP（如 `192.168.x.x`）
3. 手机浏览器打开：`http://<电脑IP>:8765/`

也可把整个文件夹发到手机，用系统浏览器直接打开 `index.html`（离线可用）。

## 使用说明
1. 首页点击「开始测试」
2. 完成 15 道单选题（可返回上一题）
3. 查看匹配结果；左右滑动浏览 6 段卡片
4. 「再测一次」重新作答；「复制结果文案」便于分享
